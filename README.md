# LINEからネイルサロンを予約できるアプリ

概要

- ネイルサロンの予約と簡単なカウンセリングができるアプリ

これまでの課題

- 同業他社であるLメッセージを作っているが課金しないとメニュー数増やせないので自分でカスマイズして出せるようになりたい
- 自分だけの黒いおしゃれでりっちなネイルサロンにあったUIで作りたい

前提条件

- BEとFEをわけてBffで開発する
- 予約者の登録情報を見たいのでデータベースを用意したい
- webアプリ

- [ ] 機能
  - [ ] ネイルサロンメニューを選択できる
  - [ ] 管理者の予定を入れる
  - [ ] 管理者が空いているカレンダーが濃く表示される
  - [ ] 予約者がカレンダーを選択し予約時間を入力して送信
  - [ ] 予約完了通知ができる
  - [ ] あとで)登録者の予約情報が管理者側から見れる
  - [ ] あとで)LINE通知がいく
  - [ ] あとで)管理者のGoogleカレンダーの予定を照合してカレンダーの空き状況を表示する

## 指針

- 昨日はめちゃくちゃシンプルにする。API開発を少しでも齧ったことのある人でもわかる内容にする。
- 内部品質にめちゃくちゃこだわる
  - 予約ボタン時の冪等性を保つ。（ボタンを一度だけ押せるようにする）
- エラーハンドリングでもユーザーには500表示とか出せないようにする
- 追跡しやすくする
  - リクエスト時にuuidをもつ
