## 足りない要件

- メニューに応じた時間と料金を表示する。
- メニューテーブルに事前に情報を入れておいてよいかも。

対応

- ユーザーが選択したメニュー内容を取得して、表示するAPIが必要
  状態管理を導入する。

- 選択したメニューの情報
- 選択した時間の情報
- フォーマット管理

ユーザーフロー
ネイル予約アプリ

1. topページ
2. /menuページでメニューを選択
3. /calendarで日程を選択肢、時間帯を選択する
4. /bookingsで予約に必要な名前と2と3で選択したメニュー情報と日にち情報がフォームに表示される。
5. 予約するボタンをおして、予約完了toastが表示される。
